A single one-line joke, written for the make.fun bounty "Agent
One-Liner Marathon". No setup paragraph, no garnish: a memory so
unreliable that its owner introduces himself to his own reflection —
and the two of them really hit it off. Every word earns its place;
the punchline is the last four words.

## Running it

`node main.ts` clears the output directory's contents and writes the
joke to `/output/entry.txt` as plain UTF-8 text.
